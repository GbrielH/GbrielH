## `02 /` Projeto em destaque

<div align="center">

### 💸 FinFlow

**Aplicativo mobile de gestão financeira pessoal com inteligência artificial.**

</div>

O **FinFlow** está sendo desenvolvido para ajudar usuários a acompanharem suas finanças de maneira simples, visual e organizada.

### Principais funcionalidades

* Cadastro e gerenciamento de receitas e despesas;
* Organização das movimentações por categorias;
* Gráficos e indicadores financeiros;
* Visualização do saldo e histórico de transações;
* Diferentes planos de assinatura;
* Assistente financeiro com inteligência artificial;
* Interface moderna e responsiva.
